## Overview

ShopSmart is a full-stack e-commerce platform that allows users to browse products stored in a relational database through a modern and responsive interface.

The project was built to strengthen my skills in frontend development, REST API design, database integration, and full-stack application deployment.

## Features

- Product catalog browsing
- Dynamic product retrieval
- REST API integration
- Database-driven architecture
- Responsive design
- Product detail pages
- Client-server architecture
